# CARVOX Garage Management — Fresh rebuild

## Features
- Dashboard with sales, received, due, expenses and net recorded
- Bills/job cards with customer, vehicle, service category, description, totals and payment mode
- Customer records
- Stock / inventory records
- Expenses
- Staff and attendance
- Suppliers and purchase records
- Search, local device storage, JSON backup export/import
- Garage name/contact settings
- CARVOX logo and frosted-glass inspired dark UI

## Build APK
1. Upload the contents of this project to your GitHub repository (keep the `.github/workflows` folder).
2. GitHub → Actions → CARVOX APK → Run workflow.
3. Download the `CARVOX-APK` artifact and install on your Android device.

Data is stored locally in the app WebView. Export JSON backup before clearing app data or reinstalling.

This is a fresh foundational rebuild. Verify the APK on-device before relying on it for business records.
